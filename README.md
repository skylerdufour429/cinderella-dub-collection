# Cinderella Dub Collection

A GitHub Pages + GitHub Codespaces-ready multilingual movie
dub collection web application.

## Movie

- **Title:** Cinderella
- **Year:** 1950
- **Studio:** Walt Disney Productions
- **Category:** Animated Feature

## Features

- HTML5 video player
- Language selector
- 46 language entries
- Individual MP4 download buttons
- Responsive design
- JSON-powered movie metadata
- GitHub Pages compatible
- GitHub Codespaces compatible
- No backend required

## Local development

Open the repository in GitHub Codespaces.

Then run a local web server.

For example:

```bash
npx serve .
